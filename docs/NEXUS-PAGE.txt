MOD NAME
RE4 Save Editor

CATEGORY / TYPE
Utilities (or "Saves" / "Tools" if the game has such a category). Not adult content.

TAGS (suggestions)
save editor, utility, inventory, attache case, money, pesetas, weapon upgrades, backup, tool

VERSION
0.9.9   (pre-release)

SHORT SUMMARY (max ~350 characters)
Unofficial local save editor for Resident Evil 4 (2023) on Steam: add weapons, change money, edit and sort your attaché case with drag and drop, upgrade weapons, change case size and look, with automatic backups. Runs on your PC, sends nothing anywhere.

REQUIREMENTS FIELD
Windows 10/11, Steam version of Resident Evil 4 (2023), Node.js 20 or newer (LTS). No .NET needed.

FILE
RE4SaveEditor-0.9.9-nexus.zip  (main file)
File description: Script-only package. Install Node.js LTS once, extract the zip, double-click Start RE4 Save Editor.js.

[color=#ff9d2e][b]Please keep a backup.[/b][/color] This is an early pre-release (0.9.9). The editor makes a backup before every write and keeps a protected first-run copy of every slot, but it is still a good idea to copy your saves yourself. Close the game before saving: if the game has saved a slot since it was started, it shows "incompatible save data" for that slot after an edit until you restart it (the slot itself is fine). Consider turning off Steam Cloud for RE4.

[size=5][b]What it does[/b][/size]
Edit your save in a clean local window: it runs on your PC and never sends your saves anywhere.
[list]
[*][b]Money[/b]: Pesetas and Spinel.
[*][b]Attaché case[/b]: add, copy and delete items (about 220 in the catalogue, grenades and eggs included), set gems in the sockets of treasures, change counts, ammo and durability, delete equipped weapons, the [b]case size[/b] and the [b]case look[/b] (Silver, Black, Leather, Gold, Classic).
[*][b]Case view[/b]: your case lying down like in the game, with an original 3D-rendered icon for every item and weapon. Drag items to move them, rotate them (R), or press [b]Sort[/b] to tidy the case. Click an item to edit everything about it, right-click it for a menu, right-click an empty place to add an item or a weapon right there.
[*][b]Add weapons[/b]: [b]Add weapon...[/b] puts a new weapon into your case (28 for the main campaign, 13 for Separate Ways), or copies one from another of your slots of the same campaign, and shows whether it fits. Not all new weapons are tested yet, and the game deletes bonus or DLC weapons you have not unlocked.
[*][b]Weapon upgrades[/b]: levels 0-4 set with steps like at the Merchant, [b]Full upgrade[/b] and [b]Upgrade all weapons[/b], and a switch for the exclusive upgrade.
[*][b]Storage[/b]: move weapons (with the attachments fitted to them) and attachments between it and the case, upgrade weapons there, put a new weapon straight into it when the case is full.
[*][b]Quick buttons[/b]: [b]Repair knives[/b] and [b]Fill ammo stacks[/b].
[*][b]Also[/b]: merchant requests (main game and Separate Ways; blue medallions are left to the game), treasures, achievement hints (read-only) and an [i]Advanced[/i] raw view for experienced users.
[*][b]Undo[/b] (button or Ctrl+Z) takes back your last changes one by one; [b]Ctrl+S[/b] saves to the game after the summary.
[*][b]Safe by design[/b]: items that overlap or stick out of the case are shown in red (the game would delete them), a summary of every change before writing, writes are decrypted back and compared before they replace the file, backup manager with restore, copy one slot into another.
[/list]

[size=5][b]Installation[/b][/size]
This package needs [url=https://nodejs.org]Node.js[/url] 20 or newer, installed once (the "LTS" Windows Installer: Next, Next, Finish). If you would rather install nothing, use the [url=https://github.com/distrix11/RE4-Remake-Save-Editor/releases]all-in-one version on GitHub[/url] instead.
[list=1]
[*]Close Resident Evil 4.
[*]Extract the whole zip anywhere and double-click [b]Start RE4 Save Editor.js[/b]. The editor opens in its own window; closing the window stops it.
[*]Optional: [b]Settings > Create desktop shortcut[/b] puts a "RE4 Save Editor" shortcut with an icon on your desktop.
[*]Pick a slot on the start screen, edit, press [b]Save to game[/b]. [b]More > Restore from backup...[/b] undoes a write at any time.
[/list]
[size=2]Windows may ask once whether to run the script (it came from the internet): choose Open / Run. If Start RE4 Save Editor.js opens in a text editor, right-click it, "Open with", "Microsoft Windows Based Script Host". The save folder is found automatically; use the gear button if you have several Steam accounts. (The all-in-one version is only on GitHub because it contains node.exe, and Nexus Mods does not accept .exe files.)[/size]

[line]

[size=5][b]Good to know[/b][/size]
[list]
[*]Item sizes in the case are estimates; a few items may look slightly different in the game.
[*]Weapon upgrade levels are limited to 0-4. A few weapons are not in the list of new weapons (Minecart Red9, Krauser's Bow, the Kitchen Knife of Separate Ways). The game deletes bonus or DLC weapons you have not unlocked.
[*]Tested on a limited set of saves and one game version. After a game patch the editor can disable structural edits and tells you why.
[*]Windows and the Steam version only.
[*]The package is plain JavaScript you can read, with no executables. One antivirus engine out of ~60 on VirusTotal shows a generic script heuristic for the start script (a false positive); the [url=https://github.com/distrix11/RE4-Remake-Save-Editor]full source is on GitHub[/url].
[/list]
