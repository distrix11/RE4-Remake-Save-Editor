MOD NAME
RE4 Save Editor

CATEGORY / TYPE
Utilities (or "Saves" / "Tools" if the game has such a category). Not adult content.

TAGS (suggestions)
save editor, utility, inventory, attache case, money, pesetas, weapon upgrades, backup, tool

VERSION
0.9.0   (pre-release)

SHORT SUMMARY (max ~350 characters)
Unofficial local save editor for Resident Evil 4 (2023) on Steam: change money, edit and sort your attaché case in a visual Case view with drag and drop, weapon upgrades, case size and look, with automatic backups. Runs on your PC, sends nothing anywhere.

REQUIREMENTS FIELD
Windows 10/11, Steam version of Resident Evil 4 (2023), Node.js 20 or newer (LTS). No .NET needed.

FILE
RE4SaveEditor-0.9.0-nexus.zip  (main file)
File description: Script-only package. Install Node.js LTS once, extract the zip, double-click start.js.

[color=#ff9d2e][b]Please keep a backup.[/b][/color] This is an early pre-release (0.9.0). The editor makes a backup before every write and keeps a protected first-run copy of every slot, but it is still a good idea to copy your saves yourself. It is best to close the game before saving (writing from the main menu and then loading the slot also works), and consider turning off Steam Cloud for RE4.

[line]

[size=5][b]What it does[/b][/size]
Edit your save in a clean local window: it runs on your PC and never sends your saves anywhere.
[list]
[*][b]Money[/b]: Pesetas and Spinel.
[*][b]Attaché case[/b]: add, copy and delete items (about 220 in the catalogue), change counts, ammo and durability, the [b]case size[/b] and the [b]case look[/b] (Silver, Black, Leather, Gold, Classic).
[*][b]Case view[/b]: your case lying down like in the game, with about 150 original 3D-rendered icons. Drag items to move them, rotate them, or press [b]Sort[/b] to tidy the case.
[*][b]Weapon upgrades[/b]: levels 0-4, a [b]Full upgrade[/b] button and a switch for the exclusive upgrade.
[*][b]Also[/b]: merchant requests, treasures, achievement hints (read-only) and an [i]Advanced[/i] raw view for experienced users.
[*][b]Safe by design[/b]: a summary of every change before writing, writes are decrypted back and compared before they replace the file, backup manager with restore, copy one slot into another.
[/list]

[size=5][b]Installation[/b][/size]
This package needs [url=https://nodejs.org]Node.js[/url] 20 or newer, installed once (the "LTS" Windows Installer: Next, Next, Finish). If you would rather install nothing, use the [url=https://github.com/distrix11/RE4-Remake-Save-Editor/releases]all-in-one version on GitHub[/url] instead.
[list=1]
[*]Preferably close Resident Evil 4.
[*]Extract the whole zip anywhere and double-click [b]start.js[/b]. The editor opens in its own window; closing the window stops it.
[*]Pick a slot at the top, edit, press [b]Save to game[/b]. [b]Restore from backup...[/b] undoes a write at any time.
[/list]
[size=2]Windows may ask once whether to run the script (it came from the internet): choose Open / Run. If start.js opens in a text editor, right-click it, "Open with", "Microsoft Windows Based Script Host". The save folder is found automatically; use the gear button if you have several Steam accounts. (Nexus Mods does not accept .exe files, so the executable version is only on GitHub.)[/size]

[line]

[size=5][b]Good to know[/b][/size]
[list]
[*]Item sizes in the case are estimates; a few items may look slightly different in the game.
[*]Weapon upgrade levels are limited to 0-4. Weapons and grenades cannot be added (copy an existing one instead).
[*]Tested on a limited set of saves and one game version. After a game patch the editor can disable structural edits and tells you why.
[*]Windows and the Steam version only.
[*]The package is plain JavaScript you can read, with no executables. One antivirus engine out of ~60 on VirusTotal shows a generic script heuristic for the start script (a false positive); the [url=https://github.com/distrix11/RE4-Remake-Save-Editor]full source is on GitHub[/url].
[/list]
