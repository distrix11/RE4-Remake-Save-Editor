Put your own item pictures here (not included in the release).

Name each file after the item ID shown in the editor (ID in the item tooltip), for example:
   114401000.png
PNG or WEBP is not required; the editor looks for <ID>.png. A picture around 128x128 (or 256x128 for weapons) with a transparent
background works best. It is shown in the Case view on top of the built-in picture.

Only use pictures you may use. Do not extract and redistribute assets of the game.
