    Settings

    Save folder (the folder that contains data001Slot.bin and the other save files)

    Found on this PC (one entry per Steam account):

    Animation effects are turned off in Windows, so "As in Windows" means no animations here. Choose "On" to see them.

    The shortcut "RE4 Save Editor" (with an icon) starts the editor from this folder. If you move the folder, create it again.

    Backups

    Add weapon

    Puts a weapon into this case (in a free cell). A new weapon comes without upgrades and with an empty magazine; a copy from one of your other slots keeps its upgrades, ammo and durability. Only weapons of the campaign of this slot are listed (the game removes weapons of the other campaign). The game also deletes bonus weapons you have not unlocked.

    Nothing selected

    Add item

    The names list is community-compiled and may contain mistakes. Weapons are added with "Add weapon…". Grenades and eggs are added here too.

    Nothing selected

    Restore a save from a backup

    The current file is copied to backup/auto/ before it is replaced.

    What will be written

    Copy slot

    The chosen slot will be replaced completely. Its current version is saved to backup/auto/. The state from the editor is copied (including unsaved edits, if any). New slots cannot be created: choose an existing one.
